# online-quiz-application

An online quiz application being built step by step to practice and demonstrate full-stack web development skills.

This project allows users to attempt multiple-choice quizzes, track their scores, and view results. The application is developed incrementally with a focus on clean code, proper project structure, and real-world development practices.

## Project Status
🚧 Work in progress (under active development)

## Planned Features
- Multiple-choice quiz questions
- Timer-based quiz
- Score calculation
- Result summary
- Responsive user interface
- Backend API for questions
- Database integration

## Tech Stack (Planned)
**Frontend**
- HTML 
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

## Learning Goals
- Improve JavaScript logic and DOM manipulation
- Understand frontend-backend integration
- Practice REST API development
- Follow Git and GitHub best practices
